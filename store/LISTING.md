# Chrome Web Store listing

## Summary (max 132 chars)
Shows the current time (HH:MM) right in your Chrome toolbar.

## Description
Clock puts the current time in your Chrome toolbar, as a tiny HH:MM icon.

Handy when your system clock is hidden: full-screen windows, auto-hidden taskbars, or minimal desktop setups.

- 24-hour HH:MM, follows your computer's clock and time zone
- Readable on both light and dark Chrome themes
- No settings, no pop-ups, no web page access
- No data collected, no network requests
- Uses only a built-in timer to refresh the time once every 30 seconds; it never reads your tabs or browsing

Tip: after installing, click the puzzle-piece icon and pin Clock to keep it visible.
